## AUFTAKT native integration — 18 October 2026, candidate 07

Alloy now compiles the recovered AUFTAKT **PCM feature frontend and observation network**, plus recovered decoder state/transition construction. This runs through Alloy's existing native research entry point with an explicit local model path. It is separate from the default Beat This control, automatic insertion, cached analysis and sessions. No standalone editor work was added.

`Source/AuftaktFeatures.*` owns the arithmetic mono mean, 44.1 kHz processing, 441-sample hop, centred 1024/2048/4096 windows, the recovered Hann formula `(1-cos(2*pi*(n+1)/(N+1)))/2`, unscaled magnitude DFT, all **4,830 recovered filter coefficients** across 22/46/92 bands, `log(1+x)*0.4342944920063019`, and 10/10/20 ms positive temporal differences. The output has **320 values per 100 Hz frame**, grouped as levels/differences for each resolution. Non-44.1 kHz conversion uses Alloy's r8brain library; matching the vendor resampler remains unverified.

`Source/AuftaktNetwork.*` evaluates the recovered three bidirectional LSTM layers (25 units in each direction per layer), followed by a three-class softmax. Gate order and row-major weight layout are verified against the **test embedded in the supplied binary**, rather than guessed from architecture labels. Every native invocation checks the selected JSON carrier's size/SHA-256 and runs that test before processing PCM. The actual carrier is local evidence, not an added distributable model asset. Its SHA-256 is `01fbd5a2c5d958ff12d9169de72f6f3e6540dde7af97efedfbc94231817eb917`.

`RhythmDecoder.*` preserves categorical **ordinary beat / downbeat / neither** observations instead of treating them as independent Beat This logits. Recovered mode uses 50 logarithmic tempo proposals with integer duration deduplication, `exp(-180*abs(newPeriod/oldPeriod-1))` transition factors, 0.95/0.05 same/other-meter bar transitions, and `neither/(40-1)` observations. The vendor transition builder does **not** normalize each predecessor row. Deterministic phase predecessors and branch-only trace storage remain bounded. Paths can change meter at bar boundaries; `meterScores` describes the **ending state**, not a fixed-meter whole-track hypothesis. Default Beat This mode retains its previous topology and observations.

Categorical zeros retain impossible-path semantics, and positive values are not raised by the independent-logit path's probability floor. If no state is reachable, the decoder returns an explicit error without a partial grid. This final correction is covered by the 45th focused check. Candidate 06's prior **951-check / 18-suite** receipt and identical construction counts remain historical; candidate 07 has its own frozen executable and verification evidence.

The frontend owns the half-open interval of nonzero reconstructed features, including spectral-window context. The research decoder uses that interval to exclude silent file padding, and preserves low-probability interior beats instead of deleting the tail at a 0.5 model threshold. This finite-file admission policy is an **Alloy choice**. Vendor block finalization/padding, interpolation or postprocessing, tie ordering and floating-point equivalence are not established by the current static recovery.
