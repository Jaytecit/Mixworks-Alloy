# Five image-generator preview — 3 November 2026

Jay approved five examples before the larger expansion, informed by Sprinkles,
Swarm, Terrain Lattice, Molten and Glitch, plus brighter palettes and continuous
particle movement. This checkpoint adds five originals: **128 scenes / 768 named
looks**. These five count towards the proposed eighty additions, leaving seventy-
five subject to review. No production activation, version bump or public release.

The movie changes palettes within each example. Source geometry/populations,
camera, image projection and motion are independent between these mechanisms.
The liquid model is an authored damped height field, not a full fluid solver.
The flock uses neighbourhoods in the source grid, not a global spatial search.

Review priorities: whether the five mechanisms are visibly distinct, whether
images genuinely participate in the result, how close their motion/character is
to Jay's chosen references, and whether palette strength and resolve timing feel
right. Native source inspection and numerical checks cannot settle those choices.

## Shared changes

Every active scene exposes `paletteStyle` and `paletteAmount`. The timeline's
right-click **Colour palette** menu selects Original colours, Electric neon,
Acid lime, Solar fire, Jewel tones, Laser primaries, Mono with accent or Soft
colours independently of the view/image methods. Palette application uses the
existing Undo/save path. Automatic arrangement retains authored palette choices
rather than generating random palette automation. Existing scenes retain their
previous default colour treatment; the five new signatures select stronger looks.

The 28 existing active particle scenes, the new shoal and the owned templates
now keep their physical simulation moving. Fragment displacement passes through
zero at image assembly, changes sign and carries on; orientation/coverage align
smoothly without a plateau. Normal transport pause remains exact. Encoded movie
frames at 16.600, 16.933, 17.167, 17.400 and 18.400 seconds show convergence,
readable assembly and continued departure in `preview-final/particle-passage.jpg`.

Explicit image-method edits recapture material atlases, while image-fed physical
or population fields retain accumulated state. New generators support both opaque
backgrounds and transparent source artwork, including their method routing.
No detector/session format/protocol changes or production cache reset.
