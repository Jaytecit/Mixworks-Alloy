# Insert a song into a completed arrangement

Import the new song into Library. Stop playback, then right-click the destination segment in **Playlist** and choose **Insert song before this segment…** or **Insert song after this segment…**. The same actions are available in the timeline segment menu and Edit menu. Before the first segment prepends a song; after the last adds an ending song. Playlist sorting does not determine the insertion destination: commands identify the actual selected segment and its chronological neighbours.

Choose a Library song, then review the prepared preview. It shows the resulting order, new join times, lane, later movement and source range. **Apply insertion** creates one Undo and sorts Playlist by timeline start so the new order is visible. Cancel at either dialog or during preparation preserves the completed mix. A changed arrangement invalidates an old preview; a missing/changed new source rejects Apply. The new song needs a reliable constant BPM and source downbeat; correct those first if unavailable. No live insertion is performed while playback, rehearsal, recording, preparation or export is active.

For a new first song, the existing mix moves later together. Between A and B, only A→B becomes A→new and new→B. Later segments across all lanes retain their relative timing and transition treatments. Labels and session automation follow the later mix; source automation, annotations, phase/slip, effects and prepared audio remain owned by their existing segments. The planner preserves the outgoing song's clock through an overlapping boundary, then resumes the translated later clock. Curved automation and tempo ramps retain their values outside the new material. Session curves hold their prefix-end values through the added middle and resume the later values at its boundary.

The new song follows the established mix tempo and keeps its source intro. Its preview explicitly reports a nondestructive tail trim of less than one source bar when needed to preserve bar phase. Existing nonzero join lengths are retained around the new song; a hard-cut boundary can receive the chosen overlap. New local treatments use the current transition default. Other manually edited transitions are retained. An unavailable source range, competing chain, occupied lanes or protected transition rejects the proposal with an explanation. Current transition locks protect absolute arrangement time, so unlock them before insertion.

Ordinary Library add/drop and Cut/Delete keep their existing behavior. Insertion does not globally run Auto Arrange or rewrite source files. The insertion feature originally used session31; current saves use session41 with analysis11; no analysis/cache reset is required.
