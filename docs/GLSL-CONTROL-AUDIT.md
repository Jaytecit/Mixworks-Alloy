## Coverage and result

The active **+ GLSL** catalogue contains 650 scenes across 182 picker groups. The source and active release indexes match, and all 650 shader/descriptor pairs are byte-identical. Every descriptor parsed through Studio's loader. Every declared control had a reference in the shader body after stripping comments and uniform declarations. The shader declarations yielded zero additional custom uniforms for Studio to infer.

Counts use named shader controls, with a vector or colour counted once. They include the eight momentary actions in standalone Studio. Shared output controls such as brightness, hue, saturation and mirror, and Sprite controls such as Injection and Beat push, are available through their own panels. Automatic audio inputs supply the existing music response. The recommended **Music response** control scales that built-in response. The timeline's Bass and Overall energy automation varies a selected control value.

The active release also has 205 GLSL-based entries in **Visuals / scenes**. Each has a valid set of 6–34 declared controls in the Originals runtime. The appendix maps every active Original to its current control set. The 70 unlisted Originals folders already have 3–21 controls. The 400 nested Studio copies under `visuals/original/scenes` match their active Studio pairs byte for byte. Archived viewer removals, externally imported shaders, passes and authoring helpers fall outside the active catalogue recommendations.

## Wiring to address

| Finding | Scope | Proposed handling |
| --- | --- | --- |
| Scene and output Saturation share one timeline key | Signal Loom | Give the shader's Saturation amount a distinct key so it can be adjusted independently of output grading. Standalone Studio stores them in separate sections. |
| Motion integrates the slider value and then multiplies that accumulated phase by TIME | Four Lit Laser Grid Horizon variants | Keep the baseline travel term and apply the accumulated Motion directly. Check constant-speed travel and changes during playback. |
| Timeline control specs omit momentary actions | Signal Loom's Fire pulse, Shrouded's Shimmer, Shock and Reset Center, and Clear Nested history in Perimeter Sweep, Convergence Sweep, Loopback Queue and Baffle Handoff | Keep momentary behaviour in Studio Live. If needed in Timeline mode, add an explicit live action route with defined behaviour during playback and seeking. |
| Motion and TIME can drive different parts of a scene | 86 of the 624 scenes with a Motion rate control reference TIME as well. Examples include Abyssal Observatory's flyby and the Lib Laser Grid scroll. | Treat Motion as a rate for the effect it drives. Use Camera sweep for a fixed camera where supported. Check any zero-motion claims against the actual shader. |

## Recommended control design

Start with the 19 scenes without controls and the eight Lib/Lit variants. Keep Motion where it already exists. For the Motion-only families, add Music response and the first two meaningful scene controls below. Add a variant-specific control where it changes the defining effect. Keep scene defaults at the existing look and use compatible keys, ranges and meanings for sibling controls. Aim for the main controls to fit the first bank of eight pots.

Use **Camera sweep** for a genuine moving camera, with zero holding a composed shot. For a layered 2D effect use its own travel, parallax or projection control. Add local artwork controls where the shader maps the sprite into a distinct material, displacement or projection. The shared Sprite controls already cover input strength and placement. Give bright beat flashes a bounded strength control where they are a defining part of the effect.

The tables describe candidate controls and observable effects. Ranges and pixel response still need validation on a candidate. For each implemented family, compare its default look and the control endpoints with quiet and active audio, and with transparent Nested artwork where relevant. Check an affected clip in Studio Timeline mode as well as Live mode. This audit used source and packaged-asset checks. It did not launch or rebuild the app.
