# WAV endings and cancellation

Use **Mix → Effect-tail window** to allow a chosen number of seconds for effects to ring after each clip. This is a saved session edit with Undo/Redo. It extends playback and the visible timeline, while song lengths, source audio, beat grids and placement stay the same. Zero retains the previous cutoff behavior. Sessions from versions 1–18 open with zero; version 19 saves the window.

**Export WAV** offers **Last clip** or **Include tail** when a positive window is configured. **Set tail…** opens the explicit session setting, then returns to the ending choice. Cancelling the export choice alone leaves the mix unchanged. The window is a deliberate duration: a plugin's advertised tail can be inaccurate, unknown or infinite, so it does not silently choose the WAV ending.

WAV output is stereo, 24-bit PCM at the current integer sample rate. Long files use JUCE's RF64 support. Export checks the planned frame count, output space and space for an existing destination's backup before rendering. Progress reports rendered seconds from 64-bit frame counts. **Cancel export** stops between processing blocks and again checks cancellation before committing the file. The existing destination is retained on cancellation or failure; successful replacement keeps an additive `.bak` copy. An export never writes to a library or arrangement source, including an existing hard-link alias.

The export job uses independent native plugin instances and copied state. It shares immutable prepared audio, so exporting does not require decoding the library again. Preparing native processors occurs on the message thread; rendering occurs on one worker; closing cancels and joins the worker before releasing processors on the message thread. The live renderer's lock is not held for the whole file, so progress and Cancel remain responsive. This is an exclusive operation: playback pauses and mix/device edits are disabled until it finishes. It does not record live MIDI.

Raw clip input stops at its musical end. Clip inserts and EQ then receive zero input through the chosen window, with post-insert gain/pan and automation still applied. Lane effects drain through the same final output window. The final device block is cut at the same exact ending sample as the WAV. Ordinary effects cannot continue as paused instrument monitoring; actual instrument chains remain playable while paused. Seeking resets effects rather than reconstructing their earlier history.

The export regression suite loads the actual test-only **Mixworks Test Delay.vst3**, with known stereo echoes at 125, 250 and 375 ms. It checks exact PCM/length, clip and lane tails, cutoff, bypass, silence, version compatibility, source identity, non-finite output, early/mid/late cancellation, backup preservation and continuous playback. Native tests exercise the ending choice, Undo/Redo, responsive progress/Cancel, retry and close during a deliberately slow offline render. This does not establish latency compensation, crash isolation, hardware or listening acceptance.
