# Section flags

With energy sections visible, forward segments without loops show small S2, S3… flags along the lower edge of their title. S1 begins at the source start; subsequent flags are suggestions from sustained energy changes, not detected verse/chorus names. Existing waveform section labels remain available.

Right-click inside a forward, unlooped segment and choose **Add Section Boundary Here...**. The position snaps to the clicked mix grid (including the selected grid division), and the dialog accepts an optional section label such as Verse, Chorus or Drop. **Add** saves the boundary immediately with the source track; Cancel changes nothing. Existing boundaries cannot be duplicated or crossed. S1 remains the implicit source start.

Select a flag and drag horizontally. Snap rounds the movement while preserving its existing phase; hold Alt for a free move. Flags stay inside the current segment and between their neighbours. Enter or a right-click opens the label and exact project-time editor. Left/Right selects adjacent flags; Up/Down moves one project beat, or four with Shift. Delete keeps the flag and segment. The exact editor's **Use suggestions** restores automatic hints for this segment. Each drag or precise change has one Undo; Cancel and unchanged entry preserve the document.

Edits use absolute source seconds and save reusable defaults with the source track. Future loads/placements reuse those boundaries. An explicit annotation snapshot already saved in a segment retains priority. Trim, audio slip, tempo mapping and movement map source coordinates into the timeline. Copied/split segments inherit independent annotations, including values currently trimmed out of view. Reverse/loop edits retain annotations but do not show editable flags until forward, unlooped playback returns. Section boundaries and [hotcues](HOTCUES.md) remain independently editable.

The first actual move saves the automatic suggestions and marks only the moved boundary as manual. Source analysis, Library corrections, waveform data and prepared audio stay intact. Labels appear beside the S number in the waveform section strip, in flag selection status and in the native accessible name. A label-only edit preserves the exact source position, including sub-microsecond precision. A manual position is not a measured energy claim. Moving a flag does not rebuild an existing transition. Explicit section-based planning reads this segment's saved positions when available.

Transition locks, preparation, export, rehearsal and automation recording protect edits. A stale exact-entry dialog must be reopened. Native list objects expose read-only source-second values; focus selects/reveals without seeking, and Enter opens the same guarded editor. A bounded native list prioritises selected and visible flags. Hands-on screen-reader and musical listening acceptance remain separate from native workflow checks.

Session format31 introduced optional per-segment flags with stable identities and strict ordering. Source defaults now use a separate version2 record (version1 remains readable), keyed by verified audio content, below Analysis-v1/sections. Undo/Redo restores the instance and its source defaults; unrelated older Undo keeps pre-existing defaults. Each drag saves once on mouse-up. Escape or unavailable/stale storage restores the preview and its Undo baseline. **Use suggestions** also resets future source defaults. Malformed/newer records are kept and edits refuse until resolved. Session35 adds optional section labels; older sessions remain readable. Labels and moved S positions survive Save/Open and fresh source imports. The versioned section record is Alloy annotation data keyed to the track, not an edit to the original audio file. Analysis revision11 and retained caches remain compatible; no detector reset is required.

The automation toolbar's compact **↓1** button opens [Save downbeat to track](DOWNBEAT-REFERENCES.md). It is separate from S/HC editing.
