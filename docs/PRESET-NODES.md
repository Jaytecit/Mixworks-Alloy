# Editable preset nodes

From 0.55.59, ordinary placement creates no transition. **None** in Add Transition creates only an explicit frame; Bass swap and Crossfade add editable nodes. Frame bounds and optional exterior muting are separate from the curves. The descriptions of automatic new-track linking below are historical.

From 0.55.39, presets place ordinary automation nodes. Bass Swap creates a full cut with a step between normal source-owned points. Crossfade, individual band modes, Filter sweeps, Auto Arrange styles, saved presets and A/B/C alternatives use the same node editor. Newly applied shapes have no additional active preset function beneath them.

Select the segment and parameter in its Automation strip. Add, drag, delete, bend, exact time/value, Read and cut-amount controls operate on the preset's nodes, including the swap itself. Each admitted edit is one Undo. A full cut is **CUT 100%**; its endpoints remain independently editable. Selecting or viewing a curve changes neither sound nor the arrangement.

From 0.55.42, empty curves show no invented endpoint nodes. Add Node (including precise entry) adds only the requested point. Add start/end points explicitly when wanted. New-track **NONE (align IN / OUT)** keeps the existing alignment-only behavior and adds no transition automation; it does not clear existing sources or analysis. Preset shapes may contain several real points to represent their envelope; continuous gain approximation remains bounded as described below.

Selecting a transition exposes vertical cut-amount handles on both participating songs without first selecting one automation curve. A cut amount changes its contiguous flat side while keeping node times fixed. RMB **Pair bass swap** accepts a partner's full cut, or its complementary opening when no cut exists. Pairing retains sharp bends; moving a paired sharp swap shifts the actual handoff while keeping its opening nodes. Conflicting points/locks still refuse atomically. Necessary exterior boundary guards remain; coincident equal-valued guards on newly applied shapes are avoided.

Applying another preset replaces its shape **inside the selected transition frame**. Individual band and Filter choices replace only that parameter. Built-in whole-transition choices and saved templates replace their standard parameter shapes in the frame. Exterior curves retain their values and bends, including curves crossing a frame boundary. Neighbouring transitions, segment positions and source audio stay in place. A conflicting Read state on an exterior draft, unavailable source or oversized conversion is refused without changing the arrangement.

Strength, gap, position and sweep-depth choices place the selected starting shape again. They are editor options; using them again replaces the corresponding frame's node edits. To retain individual edits, continue with the ordinary nodes. **Manual** retains the current band shape for normal editing. **None** clears that preset scope to the parameter's manual value while preserving exterior points. Undo restores the preceding complete shape.

The playlist recognises built-in shapes from their actual nodes. A modified shape displays **Custom / edited**; an exact saved preset name takes priority. Saving a preset captures the frame's ordinary curves, values and bends and scales their times when applied to another frame. Sessions use format36 and portable presets use format4, so older applications reject unsupported node templates. Old sessions remain readable, although their compatibility is not a development requirement.

Older arrangements can contain procedural treatments. Opening, viewing and saving them retains their original playback. Their complete effective curve is exposed for editing even when saved manual nodes already exist elsewhere on the segment. The first node edit saves the combined shape as ordinary nodes and removes that parameter's old generator on both participants, with one Undo. Legacy Filter conversion uses the normal LP / Off / HP cutoff parameter; incompatible layered filters are refused before mutation. New Filter presets directly create these regular cutoff nodes.

Gain templates approximate continuous envelopes to within .002dB above the zero-percent floor, subject to the bounded node limit. A segment Volume node at 0% mutes completely. Instant EQ swaps keep their exact sample boundary. Technical verification does not replace musical listening or physical controller checks. See [testing policy](TESTING.md) and the current [handover](../HANDOVER.md) for the accepted build and retained evidence.

From0.55.51, generated curves use sparse spans. Straight/flat sections keep only necessary endpoints; the converter fits ordinary bends for gain envelopes and stores frequency sweeps as exponential spans. It no longer bakes every sweep into dozens of linear nodes. The short filter wet entrance and real boundaries retain their necessary points. Filter conversion keeps the prior .00001 normalized-cutoff accuracy, and gain conversion retains the .002dB bound. Manual nodes are not silently simplified; old saved dense curves remain unchanged until the relevant preset is reapplied or Auto Arrange is run again.

Exponential spans use the same Add/drag/bend/Delete and exact-value controls. Inserting a point, slicing/copying, closing time, replacing a preset frame, Undo and saving preserve the interpolation kind. Old rational bends and linear/stepped curves keep their original interpretation. Older session/preset files remain readable; new format versions protect these spans from being flattened by older applications. Analysis and source-section formats are unchanged, and no source-data reset is required.


## 0.55.57 swap placement and handles

Right-click a segment **inside its transition frame**, then choose **Swaps → Place Bass/Mid/Treble/Volume swap here**. This replaces that parameter's shape within the pair at the clicked time, creates regular editable nodes and selects/reveals the receiving lane and parameter. **Pair existing full bass cut** is a separate operation: it complements a cut already present on the partner; it does not create a new arbitrary swap.

Selecting a transition, or a segment participating in it, exposes V/B/M/H paired drag handles derived from the actual ordinary-node handover. Drag either side horizontally to move both sides in musical time while retaining their gap. Sharp steps retain their opening node. Volume's short anti-click ramp and Bass fade handovers retain their shape. The nodes themselves remain individually editable. No hidden procedural treatment is reintroduced. Ambiguous multi-change curves and ordinary full-frame crossfades do not acquire guessed swap handles; use their normal nodes. Disabled Read, hidden bands, locks, outside-frame moves and crossing other nodes retain their existing protections. Saving/reopening needs no new session format.

The selected-pair band controls recognise node swaps when revisited instead of displaying None. Applying a band or Bass Swap preset now reveals the corresponding nodes on the correct lane even if another band/lane was selected. Strength/gap/position remain shape-placement controls: changing them reapplies that band's shape; paired handles and ordinary nodes edit the existing shape.
