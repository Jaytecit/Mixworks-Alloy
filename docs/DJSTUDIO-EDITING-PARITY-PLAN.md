# Editing plan — consolidated

Use W02–W03 and W17–W21 in [the roadmap](../FINISHING-PLAN.md). Direct editing and
understandable automation take priority over a parity checklist. Jay's 4 November
drag-highlight/right-click request supersedes older claims that the current editor
should simply be preserved without reassessment.

Range selection, clipboard operations, rigid groups, Repeat/Crop/Replace and local
stem separation/mixing already exist. Remaining work includes linked-transition
surgery, node groups/protection/tempo retiming, snippets/sample lanes, effect
regions, advanced treatments and stem extraction/effects. Actual gestures,
scope/Undo, saved results and audible output must be demonstrated.

[Historical EP01–EP09 design and acceptance detail](history/documentation-audit-20261104/DJSTUDIO-EDITING-PARITY-PLAN.md)
retains architecture and references. Its unchecked boxes and old proposed filenames
are not current implementation status. See [range editing](RANGE-EDITING.md),
[stems](STEM-SEPARATION.md) and the [mode contract](ARRANGE-RECORD-PERFORM-PLAN.md).
