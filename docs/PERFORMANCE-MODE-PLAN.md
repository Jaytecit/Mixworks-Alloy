## Required live workflow

1. Configure and test an explicit audience stereo pair and a separate headphone stereo pair. Enter Performance mode with clearly visible output status.
2. Keep the audience arrangement running. Select another library track, timeline segment or transition and choose **Prepare privately**. Selection alone never changes programme audio or controller targeting.
3. Use the existing lower panels to audition, seek, beatmatch, loop, set hotcues, adjust gain/EQ/filter and edit the proposed transition privately. Show a separate private cursor and waveform/transition context while the audience playhead remains visible.
4. Compare complete A/B/C transition alternatives privately while programme transport, automation and plugins continue. Preparing, switching or stopping preview cannot stop or rewind the audience mix.
5. Choose an explicit launch/apply action, showing destination, affected clips/transition and timing. Only this action changes the audience arrangement. Reject stale, locked or already-passed targets; never apply an obsolete preparation silently.
6. Mix live through deliberate programme controls, with clear automation ownership and safe hardware pickup. End private preview independently. Exiting Performance mode stops preview and cancels queued private/live launches, retains private edits in the session, and leaves programme playback/recording running. Apply and Discard remain explicit draft actions; neither happens automatically on exit. Ordinary session Save/Discard/Cancel still protects document changes on close.

| D15 — event editing and replay | Persist a starting programme snapshot and versioned continuous/discrete events on a monotonic take clock.
